# Embedded Chinese fonts

This source package includes `FandolSong-Regular.otf` and
`FandolHei-Regular.otf` (version 1.300), copyright © 2012–2013 the Fandol
team. They are used to make the XeLaTeX build self-contained with respect to
Chinese text fonts.

The fonts are distributed under GNU GPL version 3 with the Fandol document
embedding exception. The full GPL text is in `GPL-3.txt`; the exception is
reproduced in `FANDOL-EXCEPTION.txt`. The upstream package is available from
CTAN at <https://ctan.org/pkg/fandol>.
